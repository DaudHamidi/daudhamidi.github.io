# Daud Hamidi Portfolio Website

Personal portfolio website for Daud Hamidi, focused on water management, hydrogeology, climate resilience, and consulting work.

## Live Site

- https://daudhamidi.github.io

## Highlights

- Professional profile and consulting summary
- Experience, publications, methods and tools
- Awards, grants, memberships, and outreach
- Contact links including Email, LinkedIn, GitHub, ORCID, and Google Scholar

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui components

## Development

Install dependencies:

```bash
pnpm install
```

Run locally:

```bash
pnpm dev
```

Build production assets:

```bash
pnpm build
```

Type-check:

```bash
pnpm check
```

## Deployment

This repository is deployed with GitHub Pages using the workflow in `.github/workflows/deploy-pages.yml`.

Pushes to `main` trigger a new deployment.
